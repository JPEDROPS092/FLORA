# 5 · Relatório

O rascunho é montado a partir dos **dados reais do projeto ativo**: resumo, métodos, diversidade alfa e beta, composição, melhor modelo e parâmetros reprodutíveis.

## Edição

- Ative ou desative seções.
- Reescreva os textos: o texto inicial só descreve números, a **interpretação é sua**.
- Escolha a figura de cada seção.

## Exportação

HTML (fonte editável) e PDF. O PDF textual não incorpora as figuras; elas estão no HTML.

O relatório gerado pelo servidor fica em `<projeto>/reports/`.
